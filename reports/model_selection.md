# Вибір найкращої моделі

Було проведено два успішні експерименти:
- Logistic Regression;
- Random Forest.

## Порівняння результатів

| Метрика | Logistic Regression | Random Forest |
|---|---|---|
| Accuracy | 0.7835 | 0.8006 |
| Precision | 0.6055 | 0.6768 |
| Recall | 0.5294 | 0.4759 |
| F1 | 0.5649 | 0.5589 |
| ROC-AUC | 0.8279 | 0.8335 |

Основною метрикою обрано ROC-AUC, оскільки вона
оцінює здатність моделі розрізняти клієнтів
за ризиком відтоку.

За цією метрикою кращий результат показала
модель Random Forest. Логістична регресія
мала попередження про незавершену оптимізацію.

Модель Random Forest зареєстровано в MLflow
під назвою CustomerChurnClassifier, версія 1.

Версія датасету: v1.
